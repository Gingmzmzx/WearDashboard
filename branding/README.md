# WearDashboard icon

Square watch + approval check + amber pending dot, matching the watch and phone dashboard palette.

## Files

| File | Use |
| --- | --- |
| `icon.svg` | Editable master |
| `icon-512.png` | Full-bleed store/readme image |
| `icon-square-1024.png` | Rounded square master |
| `icon-round-1024.png` | Circular variant |
| `icon-foreground.png` | Adaptive foreground master |
| `icon-background.png` | Adaptive background master |
| `icon-preview.png` | Square / round / masked preview |

Android assets are generated under `app/src/main/res/drawable/ic_launcher_*.xml` (adaptive vectors) and `app/src/main/res/mipmap-*/ic_launcher*.webp` (legacy densities).

## Palette

- Background: `#050A08` to `#1D5138`
- Accent: `#67E8A5`
- Check: `#D0FFE5`
- Pending: `#F3BC55`
